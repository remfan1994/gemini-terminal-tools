ttychatter.mailbot 0.5.1 verification
======================================

Purpose
-------
Hotfix public-mode mail loops when ALLOWED_FROM=* is configured.

Changes verified
----------------
- VERSION reports 0.5.1.
- REJECT_SELF_SENDER is enabled by default.
- DENY_FROM is parsed as canonical denylist.
- BANNED_FROM and BANNED_LIST are accepted aliases for DENY_FROM.
- sender rejection runs before ALLOWED_FROM and OPEN_TO_PUBLIC.
- ALLOWED_FROM=* no longer permits MAIL_FROM to be processed when REJECT_SELF_SENDER=1.
- DENY_FROM can block mailbot@thatiam.vip even if REJECT_SELF_SENDER is disabled.
- --help, manpage, README, walkthrough, and changelog document the new keys.

Commands run
------------
python3 -m py_compile ttychatter.mailbot
ttychatter.mailbot --version
ttychatter.mailbot --help
function-level sender-policy checks through importlib
ASCII plaintext check for script and docs

Not live-tested here
--------------------
Dovecot IMAP polling
smtpd/sendmail delivery
cron execution
real public-mode loop suppression against a live mailbox
