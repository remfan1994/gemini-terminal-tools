ttychatter.mailbot 0.3.1 verification
======================================

Validated locally:

    python3 -m py_compile ttychatter.mailbot
    ttychatter.mailbot --version
    ttychatter.mailbot --help
    ttychatter.mailbot --manpage
    ttychatter.mailbot --doctor

Targeted runtime checks:

    - A fake gpg that returns:

          gpg: problem with the agent: Permission denied
          gpg: decryption failed: Bad session key

      now produces a mailbot error showing the failing .gpg file, process user,
      HOME, GPG_TTY, and recovery commands.

    - A config with missing IMAP_USER now fails locally with:

          mailbot error: IMAP_USER is unset; check CONFIG_FILE with --config

      instead of sending an invalid LOGIN command and relying on the IMAP server
      to return BAD.

    - Decrypted password output now trims trailing CR/LF only, preventing common
      echo(1) or edited-secret line-ending problems from creating invalid IMAP
      LOGIN syntax.

Not exercised here:

    live IMAP login
    live SMTP/sendmail delivery
    real local gpg-agent/pinentry unlock on the user's host
    real OpenRouter model-cache refresh
